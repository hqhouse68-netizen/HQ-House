# HQ-House cho SketchUp

Plugin tạo tủ và thao tác đường cánh chữ nhật trong SketchUp.

## Tải và cài đặt

1. [Tải HQ-House mới nhất (.rbz)](https://github.com/hqhouse68-netizen/HQ-House/releases/latest/download/HQ-House_latest.rbz).
2. Trong SketchUp, mở **Extension Manager** → **Install Extension**, rồi chọn file RBZ vừa tải.
3. Khởi động lại SketchUp và mở menu **HQ-House**.

Xem số phiên bản và mã SHA-256 tại [trang phát hành mới nhất](https://github.com/hqhouse68-netizen/HQ-House/releases/latest).
