# HQ-House cho SketchUp

Plugin tạo tủ và thao tác đường cánh chữ nhật trong SketchUp.

## Tải và cài đặt

1. [Tải HQ-House 0.20.159 (.rbz)](https://github.com/hqhouse68-netizen/HQ-House/releases/download/v0.20.159/HQ-House_0.20.159.rbz).
2. Trong SketchUp, mở **Extension Manager** → **Install Extension**, rồi chọn file RBZ vừa tải.
3. Khởi động lại SketchUp và mở menu **HQ-House**.

Các bản phát hành tiếp theo nằm tại [Releases](https://github.com/hqhouse68-netizen/HQ-House/releases).
